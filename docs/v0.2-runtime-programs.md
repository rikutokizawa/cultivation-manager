# v0.2 Runtime Programs

## 目的

Mac ローカルで完成させた backend を Raspberry Pi 5 へ移行する時に、必要な実行プログラムが既に揃っている状態にする。

## 追加したプログラム

### API

- `GET /overview`
  - おんどとり機器別の最新値、更新状態、カメラ2台分の最新画像を返す

### Services

- `backend/app/services/sensor_sources.py`
  - おんどとり現在値API
- `backend/app/services/camera_sources.py`
  - `dummy`
  - `directory`
- `backend/app/services/collection_pipeline.py`
  - センサ記録と画像記録の DB 保存

### Scripts

- `backend/scripts/collect_sensor_data.py`
  - センサ収集を 1 回またはループ実行
- `backend/scripts/capture_images.py`
  - 画像取り込み / ダミー撮影を 1 回またはループ実行
- `backend/scripts/run_runtime.py`
  - センサ収集と画像取り込みを同時に定期実行

## データ取得方針

### Sensor

- 通常取得はおんどとり現在値APIに固定する
- 取得できなかった期間はダウンロードしたTRZファイルを専用CLIで取り込む
- ローカル画面確認用データは定期収集sourceではなくseedスクリプトで投入する

### Camera

- `dummy`
  - ダミー SVG 画像を生成
- `directory`
  - `INCOMING_IMAGE_PATH` から画像を拾って登録
- `rpi`
  - `rpicam-still` または `libcamera-still` を使って撮影する

## Raspberry Pi での使い方想定

### 最小構成

- backend API を起動
- `run_runtime.py` を常駐起動
- `CAMERA_SOURCE_TYPE=directory`

センサーはおんどとり現在値APIから取得する。USBカメラは `ffmpeg` とV4L2を使って撮影する。

### 次段階

- `systemd` サービスとして backend と runtime を常駐化

## deployment 補助

- `backend/scripts/check_runtime_environment.py`
  - Pi 上のカメラコマンド有無や必要ディレクトリを確認する
- `deploy/systemd/cultivation-backend.service`
  - backend 常駐用
- `deploy/systemd/cultivation-runtime.service`
  - runtime 常駐用
